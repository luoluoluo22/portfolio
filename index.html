ENGINEERING PHILOSOPHY

我对 AI Agent 的工程认知与开发思路

从单纯调用 Prompt 到构建可靠的智能体闭环，核心在于将软件工程标准引入非确定性模型。

1. 感知层 · 真实世界的多模态捕获

Agent 不能只依赖文本输入。通过底层挂钩实现屏幕上下文感知、窗口状态识别、剪贴板捕获与视频音画波形切分，赋予 Agent 全维度的环境输入感知。

Win32 Hooks / OpenCV / Multimodal

2. 规划与编排 · 严格契约化 (Schema)

模型输出具有概率随机性，但工程执行必须确定可靠。在燕子 AI OS 中使用严格的 JSON Schema 与 Invocation Service，确保每个工具调用都有类型约束与权限沙箱。

JSON Schema / Capability Registry

3. 执行与闭环 · 物理动作与状态回传

真正的智能体能够完成物理执行。通过逆向剪映协议、操作本地进程与跨小程序通信，AI 执行后立即产生真实反馈，形成“感知 → 思考 → 执行 → 审计修正”的完整闭环。

MCP Endpoints / EventBus / Actions
