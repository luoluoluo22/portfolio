ENGINEERING PHILOSOPHY

我对 AI Agent 的工程认知与开发思路

从单纯调用 Prompt 到构建可靠的智能体闭环，核心在于将软件工程标准引入非确定性模型。

1. 感知层 · 物理环境全维捕获

智能体不能局限于单一纯文本。通过 Win32 全局挂钩、屏幕上下文识别与音视频特征提取，赋予 Agent 全维度的物理环境感知。

Win32 Hooks · 屏幕上下文 · 音视频波形

2. 规划层 · 严格契约化 (Schema-First)

模型推理具有概率随机性，但系统执行必须严格确定。通过严格的 JSON Schema 强类型约束与 Invocation 协议，确保每次工具调度安全可预测。

JSON Schema · 权限沙箱 · Invocation 契约

3. 执行层 · 物理动作与自愈闭环

真正的智能体必须深入物理桌面完成执行。逆向底层协议、操作进程并在产生故障时自动重试自愈，形成“感知-规划-执行-审计”的完整闭环。

MCP 端点 · 状态机回传 · 自动重试闭环
